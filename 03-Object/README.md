# 03 - Object in Java

## What is an Object?

An Object is an instance of a class.

When a class is created, memory is **not** allocated immediately.

Memory is allocated only when an object is created using the `new` keyword.

```java
Student s1 = new Student();
```

---

## Why Objects?

Objects allow us to:

- Store data
- Perform operations
- Represent real-world entities
- Reuse class definitions

---

## Object Creation

```java
ClassName objectName = new ClassName();
```

Example

```java
Student s1 = new Student();
```
