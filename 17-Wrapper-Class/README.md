# 17 - Wrapper Classes in Java

Wrapper classes convert primitive values into objects.

| Primitive | Wrapper |
|---|---|
| byte | Byte |
| short | Short |
| int | Integer |
| long | Long |
| float | Float |
| double | Double |
| char | Character |
| boolean | Boolean |

## Boxing

Primitive → Object

## Unboxing

Object → Primitive

## Autoboxing

Java automatically converts primitive to wrapper.

## Auto-unboxing

Java automatically converts wrapper to primitive.
