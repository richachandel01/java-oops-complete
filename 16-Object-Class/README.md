# 16 - Object Class in Java

`java.lang.Object` is the root class of the Java class hierarchy.

Every Java class directly or indirectly inherits from Object.

Important methods include:

- toString()
- equals()
- hashCode()
- getClass()
- clone()
- wait()
- notify()
- notifyAll()

## Most Important Methods

### toString()

Returns a string representation of an object.

### equals()

Compares objects logically when overridden.

### hashCode()

Returns a hash code for the object.

### getClass()

Returns runtime class information.
