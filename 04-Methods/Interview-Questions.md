# Methods - Interview Questions

## 1. What is a method?

A method is a block of code designed to perform a specific task.

## 2. Why are methods used?

For:

- Reusability
- Modularity
- Readability
- Maintainability

## 3. What is a parameter?

A variable declared in the method definition.

## 4. What is an argument?

The actual value passed to a method.

## 5. What is method overloading?

Defining multiple methods with the same name but different parameter lists.

## 6. Can we overload a method by changing only return type?

No.

## 7. What is an instance method?

A method associated with an object.

## 8. What is a static method?

A method associated with the class rather than an individual object.

## 9. Is Java pass-by-value or pass-by-reference?

Java is strictly pass-by-value.

## 10. Can a method return multiple values?

Not directly. It can return one object containing multiple values.
