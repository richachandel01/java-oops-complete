# Methods - Assignment

## Beginner

1. Create a method to print your name.
2. Create a method to add two numbers.
3. Create a method to find the square of a number.
4. Create a method to check whether a number is even.
5. Create a method to find the largest of two numbers.

## Intermediate

6. Create a method to find factorial.
7. Create a method to check prime number.
8. Create a method to reverse a number.
9. Create a method to calculate simple interest.
10. Demonstrate method overloading.

## Challenge

11. Create methods for calculator operations.
12. Create a method to find the largest element in an array.
13. Create a method to reverse an array.
14. Create a method to count vowels in a string.
15. Create a method to check palindrome.
