# Immutable - Assignment

## Beginner

1. Create an immutable Student class.
2. Create an immutable Employee class.
3. Remove all setters.
4. Use final fields.

## Intermediate

5. Create an immutable BankAccount.
6. Create an immutable Book class.
7. Compare String and StringBuilder.
8. Demonstrate final reference vs immutable object.

## Challenge

9. Create an immutable class containing a mutable ArrayList.
10. Make it truly immutable using defensive copying.
