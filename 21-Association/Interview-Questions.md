# Association - Interview Questions

## 1. What is association?

Association is a relationship between two independent objects.

## 2. What is a "has-a" relationship?

It represents one object having a reference to another object.

## 3. Can associated objects exist independently?

Yes.

## 4. What are common types of association?

- One-to-one
- One-to-many
- Many-to-one
- Many-to-many

## 5. Association vs inheritance?

Association represents relationships between objects.

Inheritance represents an IS-A relationship.
