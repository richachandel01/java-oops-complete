# Introduction to Object-Oriented Programming (OOP)

## What is Programming?

Programming is the process of writing instructions that tell a computer how to perform a specific task.

Example:
- Calculate marks
- Manage bank accounts
- Book movie tickets

---

# What is OOP?

Object-Oriented Programming (OOP) is a programming paradigm that organizes software around objects instead of functions.

An object contains:

- Data (Fields)
- Behaviour (Methods)

Example:

Student

Data
- Name
- Roll Number
- Branch

Behaviour
- Study()
- Sleep()
- Eat()

---

# Why OOP?

OOP helps developers build software that is:

- Reusable
- Secure
- Easy to Maintain
- Easy to Scale
- Easy to Test
